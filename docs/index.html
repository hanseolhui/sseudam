3단계로 시작하기

설정은 한 번에 끝나요. 어려운 건 쓰담이 알아서 해요.

설치하고 열기

맥은 처음 열 때 “응용 프로그램 폴더로 옮길까요?”에서 옮기기만 누르면 돼요.

✨ 한 번에 준비하기

수업하는 반(예: 2-1, 2-3)을 적고 한 번에 준비하기를 누르세요. 받아쓰기와 이 컴퓨터에 맞는 AI를 알아서 준비해요. 그다음 반마다 학생 명단을 붙여넣으면 끝.

휴대폰으로 말하기

쓰담 앱에서 녹음 버튼을 누르고 “김민수, 발표를 멋지게 했어요”처럼 말하세요. 컴퓨터에 학생별로 쏙쏙 들어와요.

이런 걸 해 줘요

교과·담임·동아리 선생님 모두 쓸 수 있어요.

🎙 말하면 글자로

녹음을 선생님 컴퓨터 안에서 글자로 바꿔요. 녹음이 밖으로 나가지 않고 비용도 없어요.

🧑‍🎓 학생별로 알아서

여러 학생을 한 번에 말해도 이름마다 나눠요. 반·번호 없이 이름만 말해도, “그 친구는…”처럼 이어 말해도 AI가 알아서 붙여요.

📝 세특 초안 + 바이트

교과 세특·행동특성·자율·동아리·진로 초안, NEIS 바이트 계산, 기재 금지어 경고까지.

📌 일반 메모는 따로

회의 메모처럼 학생 이야기가 아닌 녹음은 ‘일반 메모’로 따로 둬서 학생 기록이 섞이지 않아요.

☁️ 자동 백업

매일 자동 백업, 구글 드라이브 백업, 구글시트 자동 반영, 엑셀 내보내기.

✨ 알아서 업데이트

새 버전이 나오면 쉬는 틈에 알아서 바뀌어요. 기록은 그대로예요.

내 컴퓨터에서 AI가 돌아갈까요?

쓰담이 사양을 보고 알맞은 AI를 골라 줘요. 인터넷으로 학생 기록을 보내지 않아요.

자주 묻는 질문

학생 기록은 어디에 저장되나요?

선생님 컴퓨터와 선생님 본인의 iCloud(아이폰)·구글 드라이브에만 저장돼요. 쓰담 서버로 보내지 않아요. 받아쓰기와 쓰담 AI 모델도 컴퓨터 안에서 동작해요. Gemini 키를 직접 넣은 경우에만 글이 구글로 가요.

윈도우에서 “Windows의 PC 보호” 창이 떠요

새 프로그램이라 윈도우가 한 번 확인하는 창이에요. 추가 정보 → 실행을 누르면 설치돼요.

안드로이드에서 설치가 막혀요

내려받은 파일을 열 때 “출처를 알 수 없는 앱” 안내가 나오면 설정 → 이 출처 허용을 켜고 다시 열어 주세요.

아이폰 설치 버튼을 눌러도 안 돼요

App Store에서 TestFlight 앱을 먼저 설치한 다음, 이 페이지의 ‘아이폰에 설치’를 다시 눌러 주세요.

휴대폰 녹음은 컴퓨터로 어떻게 넘어오나요?

아이폰과 맥은 같은 Apple ID면 iCloud로 저절로 넘어와요. 다른 조합(안드로이드·윈도우)은 쓰담 설정 → 📱 휴대폰에서 연결해요.

맥에서 터미널로 설치·업데이트하고 싶어요
