## 1. 한눈에 보기

| 질문 | 답 |
|---|---|
| 학생 기록은 어디에 저장되나요? | **선생님 컴퓨터(맥 · 윈도우) 안에만** 저장돼요. 서리아트 서버에는 저장하지 않아요. |
| 녹음은 어디서 글로 바뀌나요? | 기본은 **선생님 컴퓨터 안에서**(Whisper 음성 인식) 바뀌어요. 녹음이 밖으로 나가지 않아요. |
| 학생이 쓰는 앱인가요? | 아니요. **교사만 쓰는 도구**예요. 학생은 계정을 만들지 않고, 학생 기기에 설치하지 않아요. |
| 회원가입이 필요한가요? | 기본 기능은 필요 없어요. 쓰담 플러스(구독)를 쓸 때만 교사 이메일로 로그인해요. |
| 학생 정보가 밖으로 나가는 경우는? | 선생님이 직접 켠 기능을 쓸 때만이에요(아래 3절). 이때도 **학생 이름은 가린 뒤** 보내거나, **암호화해서 서리아트도 볼 수 없게** 보내요. |
| 학생 정보로 광고 · AI 학습을 하나요? | 하지 않아요. |

## 3. 학생 정보가 컴퓨터 밖으로 나가는 경우 (모두 선생님이 직접 켜야 함)

| 기능 | 나가는 내용 | 보호 방법 | 받는 곳 |
|---|---|---|---|
| **쓰담 플러스 AI**(구독) | 학생별 정리 · 초안을 만들 관찰 기록 글 | 보내기 전에 선생님 컴퓨터에서 명단의 **학생 이름을 '학생1'처럼 가림** → 답을 받은 뒤 다시 이름으로 바꿈. 서리아트 서버는 **내용을 저장하지 않고** 횟수만 셈 | 서리아트 서버(Vercel, 일본 도쿄) → Anthropic API(미국) |
| **휴대폰 ↔ 컴퓨터 QR 연동** | 휴대폰에서 녹음한 파일 · 기록 | QR 안의 256비트 열쇠로 **암호화한 덩어리만** 중계 서버를 거침. 열쇠는 서버에 없어서 **서리아트도 내용을 볼 수 없음**. 위 · 변조 검증(HMAC-SHA256) | Cloudflare 중계 서버. 받은 쪽이 바로 지우고, 남은 것도 14일 뒤 자동 삭제 |
| 선생님 본인 API 키 연결(고급) | 관찰 기록 글 | 선생님 본인 계정 · 키로 직접 연결 | 선생님이 고른 Google · OpenAI · Anthropic |
| 구글시트 반영 · 드라이브 백업 | 학급 기록표 · 백업 파일 | 선생님 본인 구글 계정 | 선생님 구글 계정 |

**학교 권장 설정:** 쓰담 플러스를 쓰지 않는 경우, 설정 → AI에서 '쓰담 AI 모델'(컴퓨터 안에서 동작) 또는 'AI 없이'를 고르면 학생 정보가 컴퓨터 밖으로 나가지 않아요.

### 이름 가리기의 한계 (투명하게 알려 드림)
- 명단에 있는 이름(성 뺀 이름, 다르게 들릴 수 있는 이름 포함)을 가려요.
- 받아쓰기 오류로 **명단과 많이 다르게 적힌 이름**은 가려지지 않을 수 있어요. 선생님이 '다르게 들릴 수 있는 이름'을 명단에 적어 두면 줄일 수 있어요.

## 6. 안전성 확보 조치

| 분야 | 조치 |
|---|---|
| 저장 최소화 | 학생 기록은 교사 컴퓨터에만. 서버는 AI 요청 내용을 저장하지 않음 |
| 전송 보호 | 모든 통신 HTTPS(TLS). QR 연동은 추가로 종단간 암호화 |
| 접근 통제 | 쓰담 프로그램은 그 컴퓨터 안에서만 접속 가능(127.0.0.1). 서버 DB는 전용 계정 · 행 단위 보안(RLS) · 최소 권한 |
| 인증 | 쓰담 플러스는 이메일 인증번호 로그인. 로그인 토큰은 서버에 원문이 아닌 해시(SHA-256)로만 보관. 계정당 컴퓨터 3대 |
| 남용 방지 | 요청 횟수 제한, 인증번호 시도 제한 |
| 결제 | 카드 번호는 결제 대행사만 보관. 해지하면 결제용 열쇠(빌링키)를 바로 삭제 |
| 로그 | 서버 로그에 기록 내용을 남기지 않음(오류 종류만) |
| 업데이트 | 서명 · 공증된 설치 파일(맥), 자동 업데이트 시 기록 자동 백업 |

**교사 컴퓨터 권장 사항:** 컴퓨터 로그인 암호 사용, 디스크 암호화(맥 FileVault · 윈도우 BitLocker) 켜기, 공용 컴퓨터에는 설치하지 않기.

## 7. 파기

- 학생 기록: 선생님이 쓰담에서 지우거나 프로그램 데이터 폴더를 지우면 삭제돼요(휴지통 기능은 30일 보관 후 삭제).
- QR 연동 중계: 받은 즉시 삭제, 남은 것은 14일 뒤 자동 삭제.
- 서리아트 보관 정보: 2-2절 보관 기간이 지나거나 삭제를 요청하면 지체 없이 삭제(법령상 보관 의무 정보 제외).
