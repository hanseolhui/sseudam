# 쓰담 플러스 정기결제 신청 · 연결 안내

결제 코드, 구독 관리 페이지, 약관, 환불 규정, 개인정보 처리방침은 준비돼 있어요 (toktok-server `sseudam-plus` 브랜치).
아래는 계정 로그인 · 서류 · 계약 동의가 필요해서 직접 해 주셔야 하는 부분이에요.

## 1. 심사용 페이지 먼저 열기 (배포만 하면 됨)
PG사는 심사 때 판매 페이지 · 약관 · 환불 규정 · 사업자 정보가 웹에 떠 있는지 확인해요.
`sseudam-plus` 브랜치를 main 에 합치면 아래 주소가 열려요. 정기결제 채널 키가 없는 동안 페이지에는 "정기결제를 준비하고 있어요"만 보이고, 쓰담 앱은 바뀌지 않아요.

- 판매 · 구독 관리: https://apps.seoriarts.com/sseudam/plus
- 이용약관 · 환불 규정: https://apps.seoriarts.com/sseudam/plus/terms
- 개인정보 처리방침: https://apps.seoriarts.com/sseudam-privacy
- 서비스 소개: https://apps.seoriarts.com/sseudam

## 2. 포트원 콘솔에서 정기결제 채널 신청
1. admin.portone.io 로그인 → 톡톡과 같은 상점(서리아트) 선택
2. **결제 연동 → 채널 관리 → 실연동 → 채널 추가**
3. PG사 선택 — 추천: **토스페이먼츠 (카드 정기결제 / 빌링)**. 다른 선택지: KG이니시스 정기결제, 카카오페이 정기결제(별도 CID)
4. 결제 방식: **빌링키 발급(정기결제)** · 결제 수단 **카드**
5. PG사 계약 신청서 작성 — 보통 필요한 것: 사업자등록증, 대표자 신분증, 정산 받을 사업자(대표자) 통장 사본. PG사가 추가로 요청하면 그대로 내면 돼요.
6. 신청서에 적을 내용 (복사해서 쓰기)
   - 상호: 서리아트(SeoriArts) · 사업자등록번호 824-41-01427 · 통신판매업 2026-경기파주-0156
   - 서비스명: 쓰담 플러스 (교사용 관찰 기록 정리 프로그램 '쓰담'의 AI 구독)
   - 판매 상품: 디지털 서비스 구독 (배송 없음)
   - 가격: 월 9,900원 · 6개월 29,000원 · 12개월 49,000원 (부가세 포함), 카드 등록 시 14일 체험 후 자동 결제
   - 판매 URL: https://apps.seoriarts.com/sseudam/plus
   - 환불 규정 URL: https://apps.seoriarts.com/sseudam/plus/terms#refund
   - 고객센터: help@seoriarts.com · 평일 10:00–18:00
7. 심사는 보통 1~3주. 승인되면 채널 목록에 **채널 키**(channel-key-…)가 생겨요.

> 테스트 채널은 심사 없이 바로 만들 수 있어요. 채널 추가에서 **테스트** 탭으로 토스페이먼츠 테스트 채널을 만들면, 실제 돈이 나가지 않는 카드 등록 · 결제를 미리 해 볼 수 있어요.

## 3. 승인 뒤 연결 (Vercel → toktok-server → Settings → Environment Variables)
| 이름 | 값 | 비고 |
|---|---|---|
| `PORTONE_BILLING_CHANNEL_KEY` | 정기결제 채널 키 | 공개돼도 되는 값 |
| `CRON_SECRET` | 아무 긴 무작위 글자 (32자 이상) | 매일 자동 결제 크론 보호용. Vercel 이 알아서 실어 보냄 |
| `ANTHROPIC_API_KEY` | console.anthropic.com 에서 발급 | 쓰담 플러스 AI 용 |
| (이미 있음) `PORTONE_STORE_ID`, `PORTONE_API_SECRET` | 톡톡과 같은 값 | |

넣고 다시 배포하면 구독 페이지의 "카드 등록하고 2주 체험 시작" 버튼이 켜져요.

## 4. 연 뒤 확인 순서
1. 테스트 채널 키로 먼저: 구독 페이지 로그인 → 카드 등록 → 체험 시작 메일 → 관리자 사용자 · 쓰담 탭에서 '2주 체험 · 자동 결제 날짜' 확인
2. 해지 → 해지 메일 · 카드 정보 삭제 확인
3. 실채널 키로 바꾼 뒤 본인 카드로 월간 1번 결제 → 영수증 메일 → 관리자에서 환불(포트원 콘솔 결제 취소)
4. 쓰담 앱 `app/plus.py` 의 `ENABLED` 를 True 로 바꿔 배포 (ARCHITECTURE.md '쓰담 플러스' 참고)

## 자동으로 돌아가는 것
- 매일 오전 10시(한국 시간): 결제 3일 전 안내 메일 → 결제일이 된 구독 결제 → 실패하면 3일 동안 하루 한 번 재시도(그동안 계속 사용 가능) → 그래도 실패하면 자동 결제 멈춤 + 메일
- 결제 · 실패가 있던 날은 관리자 메일로 요약
- 해지하면 빌링키(카드 정보)를 바로 지우고, 결제한 기간이 끝날 때까지 사용
