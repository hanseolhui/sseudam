쓰담 개인정보 처리방침

적용 대상: 쓰담 (아이폰·안드로이드 녹음 앱, 맥·윈도우 프로그램) · 시행일 2026년 10월 24일

요약 — 학생 정보와 기록 내용은 쓰담 개발자가 수집하지 않습니다. 녹음과 기록은 선생님의 기기와 선생님 본인 계정의 iCloud·구글 드라이브에만 저장됩니다. 맥·윈도우 프로그램은 문제 해결과 업데이트 지원을 위해 익명 사용 정보와 컴퓨터 사양을 하루 한 번 보냅니다(설정에서 끌 수 있음).

1. 처리하는 정보와 저장 위치

  • 녹음 파일: 휴대폰 앱 안에 저장되고, 선생님이 켠 경우 선생님 본인의 iCloud Drive('쓰담' 폴더) 또는 선생님 본인의 구글 드라이브('쓰담 녹음함' 폴더)로 전송됩니다.
  • 학생 명단·관찰기록·초안: 선생님 컴퓨터의 쓰담 프로그램 안(맥: ~/Library/Application Support/쓰담, 윈도우: %APPDATA%\쓰담)에만 저장됩니다. 선생님이 연결한 경우 선생님 본인의 구글시트·구글 드라이브에 사본과 백업이 저장됩니다.
  • 연결 정보: 휴대폰 앱은 컴퓨터와 연결할 때 받은 '녹음 올리기 전용' 주소와 열쇠만 기기 안에 보관합니다. 이 열쇠로는 기록을 읽을 수 없습니다.

2. 개발자가 수집하는 정보 (맥·윈도우 프로그램)

문제 해결과 업데이트 지원을 위해 하루 한 번 아래 정보를 서리아트 서버로 보냅니다. 학생 이름·명단·녹음·관찰기록·초안 내용은 보내지 않습니다.

  • 늘 보내는 정보 (익명): 무작위로 만든 설치 번호, 쓰담 버전, 운영체제 종류와 버전, 컴퓨터 사양(칩·메모리·그래픽), 고른 AI 종류와 모델 이름, 받아쓰기 방식, 학급·학생·기록·녹음의 개수(숫자만)
  • 선생님이 직접 적고 보내기로 한 경우만: 이메일, 이름, 학교 — 업데이트·문제 해결 안내를 드리기 위해 씁니다.

이 정보는 서리아트(쓰담 개발자)가 운영하는 서버(Supabase, 일본 도쿄)에 보관하며, 위 목적 밖으로 쓰거나 다른 곳에 넘기지 않습니다. 쓰담 설정 → 백업·업데이트 → 사용 정보 보내기에서 언제든 끌 수 있고, 지워 달라고 하시면 지웁니다. 휴대폰 앱은 이런 정보를 보내지 않습니다.

3. 외부 서비스

  • Apple iCloud, Google 드라이브·시트: 선생님이 직접 켜고 본인 계정으로 연결한 경우에만 사용되며, 각 회사의 개인정보 처리방침이 적용됩니다.
  • 받아쓰기: 기본값은 컴퓨터 안에서 동작하는 음성 인식(Whisper)이라 녹음이 외부로 나가지 않습니다. 선생님이 설정에서 Google Gemini를 고른 경우에만 선생님 본인의 API 키로 Google에 전송됩니다.
  • 학생 나누기·초안 AI: 기본인 쓰담 AI 모델·기기 안 AI는 컴퓨터 안에서 동작합니다. 선생님이 본인의 Gemini API 키를 넣거나, 프롬프트를 직접 Gemini·ChatGPT 웹에 붙여넣는 경우에만 해당 서비스로 전송됩니다.

4. 기기 권한

  • 마이크: 녹음을 위해 사용합니다. 선생님이 녹음 버튼을 누른 동안에만 녹음합니다.
  • 카메라: 컴퓨터 화면의 연결 QR을 찍을 때만 사용하며, 사진을 저장하지 않습니다.
  • 알림(안드로이드): 화면이 꺼진 상태에서 녹음 중임을 표시합니다.

5. 보관과 삭제

녹음은 학기말 학교생활기록부 작성까지 보관할 수 있도록 자동으로 지우지 않습니다. 선생님이 앱·프로그램에서 직접 지우거나 앱을 삭제하면 기기 안의 데이터가 삭제됩니다. iCloud·구글 드라이브에 저장된 사본은 선생님이 해당 서비스에서 직접 지울 수 있습니다.

6. 학생 개인정보 보호 안내

쓰담은 교사의 학교생활기록부 작성을 돕는 도구입니다. 학생 개인정보는 소속 학교와 교육청의 개인정보 보호 지침에 따라 다뤄 주세요.
