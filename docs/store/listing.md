## 이름
쓰담

## 짧은 설명 (검색 결과 · 100자 안팎)
수업 중 말로 남긴 학생 관찰을 학생별로 정리하고, 학교생활기록부 초안까지 도와주는 교사용 프로그램.

## 설명
쓰담은 선생님이 수업이나 상담 중에 말로 남긴 관찰을 학생별로 정리해 주는 프로그램이에요.

녹음하면 이 컴퓨터 안에서 글자로 바뀌고(Whisper), 학생 이름이 나온 곳을 기준으로 학생별 관찰 기록으로 나뉘어요. 쌓인 기록으로 과목별 세부능력 및 특기사항, 행동특성, 창의적 체험활동 초안을 만들 수 있어요.

학생 기록은 선생님 컴퓨터에만 저장돼요. 기본 기능은 인터넷 없이 컴퓨터 안에서 동작하고, 학생 정보를 밖으로 보내지 않아요.

주요 기능
• 녹음 → 받아쓰기 → 학생별 관찰 기록 자동 정리
• 학급 · 학생 명단 관리, 학생별 기록 모아 보기
• 세특 · 행동특성 · 창체 초안 작성, NEIS 바이트 수 확인
• 휴대폰(아이폰 · 안드로이드) 쓰담 앱과 QR로 연결: 교실에서 녹음하면 컴퓨터로 암호화되어 전달
• 컴퓨터 안에서 동작하는 AI 모델(선택), ChatGPT · Gemini 프롬프트 복사
• 자동 백업, 엑셀 · 구글시트 내보내기

쓰담 플러스(선택 · 별도 구독)
키나 모델 설치 없이 서버 AI로 학생별 정리와 초안을 더 정확하게 만들어요. 보내기 전에 학생 이름은 컴퓨터에서 '학생1'처럼 가려져요.

개인정보 처리방침: https://apps.seoriarts.com/sseudam-privacy

## 새로운 기능 (이번 버전)
윈도우에서 한글 사용자 이름 · 폴더에서도 받아쓰기와 내장 AI가 동작해요. 받아쓰기가 이름 사이에 띄어쓰기를 넣어도 학생을 알아봐요.

## 제품 특징 (최대 20개)
- 말로 남긴 관찰을 학생별로 자동 정리
- 컴퓨터 안에서 받아쓰기 (인터넷 · 비용 없음)
- 학교생활기록부 초안 작성 도우미
- NEIS 바이트 수 확인
- 휴대폰 앱과 QR 연결 (종단간 암호화)
- 학생 기록은 선생님 컴퓨터에만 저장

## 검색어 (최대 7개)
교사, 생활기록부, 세특, 관찰기록, 받아쓰기, 학생기록, 수업

## 가격
무료 (앱 다운로드). 쓰담 플러스는 웹에서 결제하는 별도 구독 — 앱 안에서 판매하지 않음.

## 제한된 기능 사용 이유 (runFullTrust) — 인증 참고 사항
쓰담은 데스크톱(Win32) 프로그램을 MSIX로 묶은 앱이에요. 받아쓰기(whisper.cpp)와 컴퓨터 안 AI(llama.cpp) 실행 파일을 직접 실행하고, 이 컴퓨터 안(127.0.0.1)에서만 열리는 로컬 서버로 화면을 보여 주기 때문에 runFullTrust 가 필요해요. 외부 서버를 열지 않으며, 학생 기록은 사용자 폴더(%USERPROFILE%\쓰담)에만 저장해요.

## 인증 참고 사항 (심사자에게)
- 앱을 실행하면 기본 브라우저(Edge) 앱 창으로 화면이 열려요.
- 처음 실행 시 안내에 따라 학급을 만들고, '녹음 올리기' 또는 '글로 붙여넣기'로 바로 시험할 수 있어요.
- 받아쓰기 모델은 설정 → 받아쓰기 엔진에서 받아요(약 190~550MB, Hugging Face).
- 로그인 없이 모든 기본 기능을 쓸 수 있어요. 쓰담 플러스는 선택 기능이에요.
