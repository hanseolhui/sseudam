# 스토어 결제 전환

- 사용자 확정: Apple App Store와 Google Play에서만 신규 구매. 관리자 라이선스 부여 유지.
- 서버: plans/billing에서 웹 채널 반환 중단, subscribe 403. 스토어 영수증 검증 및 관리자 grant 경로 변경 없음.
- 기존 웹 결제 완료/웹훅/해지/환불 경로는 기존 구매자 보호를 위해 유지.
- 홈페이지와 구독 페이지는 스토어 구매·복원 및 동일 계정 사용 안내로 교체.
- Mac·Windows 앱과 직접 설치 Android 안내 소스 수정. 설치 패키지는 v1.10.30으로 재빌드·공개 배포 완료. 기존 설치판도 서버의 웹 결제 차단 적용 대상.
- 테스트 3개 통과. 커밋 e4bfb73 (서버 정책 변경 17eae31).
- 아야는 기존 Apple/Google 결제 경로 유지, 앱/서버 라이선스 관련 수정 없음.
- 실제 스토어 신규 구매·복원 재시험은 별도 확인 필요. 설치 패키지 배포 완료.

## v1.10.30 배포 검증
- Mac Developer ID 서명·앱 및 DMG 공증 Accepted. 설치 앱 spctl 평가 accepted.
- Windows EXE, Android 직접 설치 APK, Mac DMG/ZIP 및 앱 업데이트 ZIP 공개 릴리스 업로드 완료. Homebrew 갱신 완료.
- 로컬 설치 앱 버전 1.10.30 확인. 기존 운영자 무제한 권한 및 구독 안내 링크 유지 확인.
- 학생·녹음·초안 데이터베이스 행 비교 일치, 음성 파일 수 유지. 업데이트 전 데이터베이스와 이전 앱은 사용자 Application Support 아래 백업.
- 구독 상태 테스트 9개, AI 안내 테스트 3개 통과. APK 서명 및 배포 ZIP 버전/스토어 안내 확인.
- Windows 실기기 실행 및 신규 실제 결제는 이번 확인 범위에 포함하지 않음. Google Play AAB는 빌드했지만 이번 설치 파일 릴리스 작업에서 별도 스토어 심사 제출은 하지 않음.
